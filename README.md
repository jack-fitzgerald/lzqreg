# lzqreg: Stata command for logarithmic quantile regression with nonpositive values in the data

**This command can be downloaded from SSC using the following Stata code:**
```
ssc install lzqreg
```

Alternatively, you can install this package from GitHub with the following Stata code:
```
net install lzqreg, from("https://raw.githubusercontent.com/jack-fitzgerald/lzqreg/main/") replace
```
Please cite the papers underlying this package: <br/>
Fitzgerald, J., Adema, J., Fiala, L., Kujansuu, E., & Valenta, D. (2026). "Non-Robustness in Log-Like Specifications." MetaArXiv. https://doi.org/10.31222/osf.io/juda7_v1 <br/>
Liu, X., & Kaplan, D. M. (2025). "Quantile Regression with Log(0) Outcomes." https://drive.google.com/file/d/1F3dnhm8MrlO5aRrGt48rBWAEaBqdCBH-/view
